# Цель работы

Изучить основы программирования в оболочке ОС UNIX. Научится писать более сложные командные файлы с использованием логических управляющих конструкций и циклов.

# Задания

1. Используя команды getopts grep, написать командный файл, который анализирует командную строку с ключами:
- -iinputfile — прочитать данные из указанного файла;
- -ooutputfile — вывести данные в указанный файл;
- -pшаблон — указать шаблон для поиска;
- -C — различать большие и малые буквы;
- -n — выдавать номера строк.
а затем ищет в указанном файле нужные строки, определяемые ключом -p.

2. Написать на языке Си программу, которая вводит число и определяет, является ли оно больше нуля, меньше нуля или равно нулю. Затем программа завершается с помощью функции exit(n), передавая информацию в о коде завершения в оболочку. Командный файл должен вызывать эту программу и, проанализировав с помощью команды $?, выдать сообщение о том, какое число было введено.

3. Написать командный файл, создающий указанное число файлов, пронумерованных последовательно от 1 до 𝑁 (например 1.tmp, 2.tmp, 3.tmp,4.tmp и т.д.). Число файлов, которые необходимо создать, передаётся в аргументы командной строки. Этот же командный файл должен уметь удалять все созданные им файлы (если они существуют).

4. Написать командный файл, который с помощью команды tar запаковывает в архив все файлы в указанной директории. Модифицировать его так, чтобы запаковывались только те файлы, которые были изменены менее недели тому назад (использовать команду find).

# Контрольные вопросы

1. Каково предназначение команды getopts?
Ответ: Команда getopts предназначена для разбора параметров (ключей) командной строки в shell-скриптах.

2. Какое отношение метасимволы имеют к генерации имён файлов?
Ответ: Метасимволы используются оболочкой (shell) для генерации имён файлов, то есть для автоматического подбора файлов по шаблону. Этот механизм называется globbing.

3. Какие операторы управления действиями вы знаете?
Ответ: В shell-скриптах используются следующие операторы управления действиями:
  1. Условные операторы:
     - if
     - then
     - else
     - elif
     - fi
  2. Операторы выбора: case ... in ... esac
  3. Циклы:
     - for
     - while
     - until
  4. Операторы логики:
     - && — логическое И
     - || — логическое ИЛИ
     - ! — отрицание
  5. Операторы для прерывания цикла:
     - break	- полностью завершает цикл
     - continue	- пропускает текущую итерацию
  6. Команды для возврата логических значений через код завершения:
     - true	0 (успех)
     - false	1 (ошибка)
  7. Разбор:
     - test — команда проверки условия;
     - -f — проверка существования обычного файла;
     - man$s/$i.$s — имя файла, составленное из переменных.

4. Какие операторы используются для прерывания цикла?
Ответ:
- break	- полностью завершает цикл
- continue	- пропускает текущую итерацию

6. Для чего нужны команды false и true?
Ответ:  Команды для возврата логических значений через код завершения:
- true	0 (успех)
- false	1 (ошибка)

7. Что означает строка if test -f man$s/$i.$s, встреченная в командном файле?
Ответ:
- test — команда проверки условия;
- -f — проверка существования обычного файла;
- man$s/$i.$s — имя файла, составленное из переменных.

8. Объясните различия между конструкциями while и until.
Ответ:
- while	пока условие истинно
- until	пока условие ложно
